# Plataforma gamificada de Seguridad del Paciente

Formación y concienciación en seguridad del paciente para **ciudadanía** y **profesionales**
(Aprende · Practica · Juega), alineada con la Estrategia para la Seguridad del Paciente del
Sistema Sanitario Público de Andalucía.

- **Sin instalación ni servidor de aplicaciones**: HTML, CSS y JavaScript estáticos. Basta con
  copiar esta carpeta a cualquier servidor web.
- **Sin Inteligencia Artificial** y **sin servicios externos de datos**.
- **Privacidad**: no se piden datos personales; puntuaciones y encuestas se guardan solo en el
  navegador de cada persona. `js/core/almacen.js` permite conectarlo a un servidor corporativo.
- **Versiones**: `version.json`, `js/core/version.js` y `CHANGELOG.md`. Ayuda en `ayuda/ayuda.html`.

Para probarla en un ordenador: abrir una terminal en esta carpeta, ejecutar
`python3 -m http.server 8080` y entrar en http://localhost:8080.
